## PalGate

- Device ID / טלפון לפיילוט סביון נשמרו אצל הבעלים — **אין** session token עד Device Linking.
- החלטה: לחכות למייל רשמי לפני פתיחת שער חיה.
- **כפר דוד:** לא ב־allowlist (`lib/palgate/pilot.ts`) עד אישור מסחרי + החלטת בעלים.
