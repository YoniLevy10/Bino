## עקרון — חשבון אישי + עמוד Grow אישי

**אין חשבון Morning / כתובת סליקה משותפת במקור.**  
כל לקוח מזין בהגדרות → Morning את מפתחות ה-API של **החשבון שלו**. הכסף מהדיירים נכנס לסליקה של אותו חשבון.

**אין עמוד Grow משותף לפיילוט.**  
כל לקוח ממלא שם/טלפון/כתובת של **העסק שקולט את הכסף** ומדביק ב-Morning את `/vaad-pay/{clientId}` — לא את `/vaad-pay` של הפלטפורמה.

### אישור Grow (B8–B9)

1. הלקוחה שומרת פרטי עסק בהגדרות → Morning.
2. פותחים את `/vaad-pay/{clientId}` בלי התחברות ומוודאים שם + טלפון + כתובת **שלה**.
3. ב-Morning שלה → תשלומים דיגיטליים: כתובת האתר = **אותו קישור** (לא `/vaad-pay` הכללי, לא אתר אחר).
4. עדכון → המתנה עד ש-Grow מוריד «ממתין לאישור».
5. רק אחרי אישור — תשלום ניסיון (B6).

**רק אחרי B6 מסומן — מותר לדבר עם הלקוחה.**
