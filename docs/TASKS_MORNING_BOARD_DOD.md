# DoD — מסך בוקר משימות (W1)

לפני סגירת גל W1 כ־done:

1. ב־`/tasks` ברירת הסינון היא **בוקר**.
2. מוצגות משימות פתוחות עם due ב־**עבר / היום / השבוע** בלבד.
3. לכל משימה נקודת צבע לפי **מחזוריות** (שבועי/חודשי/רבעוני/שנתי) — לא לפי עדיפות.
4. אגדת צבעים גלויה ליד הסינון.
5. ביצירה/עריכה אפשר לבחור `cadence`; שמירה עם due מסנכרנת ליומן (אם תוסף calendar פעיל) כ־`event_type=maintenance`.

צפון־כוכב: מנהל נכנס בבוקר ורואה מה חסר / באיחור בלי לפתוח כמה מסכים.
