# סרטון מערכת BINO (Appshot)

סרטון דמו מוצר 1920×1080 (~33 שניות) שנוצר עם [Appshot](https://github.com/trunghaiy/appshot) + Remotion.

## נרטיב (Flywheel)

1. **Hook** — לא עוד מערכת תקלות
2. **זיכרון תפעולי** — היסטוריית בניין בדשבורד
3. **שיוך חכם** — המלצה לעובד · 48→12 דק׳
4. **הוכחת חיסכון** — מדדי כוכב צפוני
5. **CTA** — תיאום הדגמה · bino.app

## פקודות

```bash
cd appshot-video
npm install
npm run dev      # Remotion Studio
npm run build    # → out/ProductDemo.mp4
```

הקובץ המרונדר מועתק גם ל־`public/marketing/bino-system-demo.mp4` לשימוש בדף הנחיתה / מכירות.
